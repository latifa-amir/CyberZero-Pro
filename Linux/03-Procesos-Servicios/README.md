# Procesos y Servicios
## Objetivo
Aprender a ver, entender y gestionar los procesos y servicios que se ejecutan en Linux, para poder diagnosticar problemas como lentitud del sistema o servicios que no responden.
## Estado
- Módulo completado.
## Conceptos aprendidos
- Diferencia entre ps (sesión actual) y ps aux (todos los procesos)
- Lectura de columnas clave: USER, %CPU, %MEM, STAT
- Visualización en tiempo real con top
- Filtrado de procesos con grep
- Ordenación de resultados con --sort y head
- Diferencia entre kernel Linux, distribución y entorno de escritorio
- Gestión de servicios con systemctl: status, stop, start
- Lectura del estado de un servicio: Active, Loaded, actividad reciente.
## Lo que he comprendido
En este módulo he aprendido a ver qué procesos están corriendo en mi sistema y cuánta CPU o memoria consume cada uno, lo cual es clave para diagnosticar por qué un sistema puede ir lento. También he aprendido a gestionar servicios reales con systemctl, parándolos y arrancándolos de forma controlada, y a leer su estado para saber si están funcionando correctamente. Además, he entendido mejor cómo se organiza Linux en capas: el núcleo, la distribución (Ubuntu) y el entorno de escritorio (GNOME).
