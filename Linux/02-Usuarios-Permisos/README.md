# Usuarios y Permisos
## Objetivo
Aprender a gestionar usuarios, grupos y permisos en Linux, entendiendo quién puede leer, escribir o ejecutar cada archivo o carpeta.
## Estado
- Proyecto iniciado
## Conceptos aprendidos
- Estructura de permisos: usuarios, grupo, otros (rwx)
- Comando chmod para modificar permisos
## Lo que he comprendido
En este módulo he aprendido que todo archivo y carpeta en Linux tiene un propietario y un grupo, y que los permisos determinan qué puede hacer cada uno de ellos (leer, escribir, ejecutar). También he practicado el uso de chmod para modificar estos permisos de forma controlada.
## Próximo objetivo
Seguir practicando con chmod y aprender la gestión de usuarios (adduser, usermod).
