# Caso 01 - Estructura inicial del proyecto
## Objetivo
Crear la estructura de carpeta base del proyecto y dejar constancia de su estado incial como evidencia.
## Acciones realizadas
- Creación de la estructura de carpeta con 'mkdir -p'
- Generación de una evidencia del estado inicial con 'ls -R' y redirección '>'
- Verificación del contenido con 'cat'
## Comandos utilizados
mkdir -p proyecto/documentos proyecto/scripts proyecto/evidencias
ls -R proyecto > proyecto/evidencias/estructura_inicial.txt
## Resultado
Estructura creada correctamente y evidencia guardada en proyecto/evidencias/estructura_inicial.txt
## Lo que he aprendido
- Diferencia entre crear carpetas (mkdir) y crear/redirigir contenido a archivos (>)
- Diferencia entre > (sobrescribe) y >> ( añade)
- Uso de rm para eliminar archivos
